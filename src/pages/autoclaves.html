Автоклавы

Автоклавные установки для изготовления деталей из полимерных композиционных материалов (ПКМ) конструкционного назначения.

Автоклавные установки применяются для изготовления деталей из ПКМ методом автоклавного формования — формообразования детали при повышенной температуре и давлении с выдержкой в течение заданного времени для полной полимеризации клеевого связующего. Основная часть композиционных деталей конструкционного назначения изготавливается из клеевых препрегов.

Режим формования

  1. Нагрев под вакуумом до заданной температуры.
  2. Подача заданного давления, отключение вакуума.
  3. Выдержка при заданной температуре в течение заданного времени.
  4. Охлаждение под давлением, сброс давления.

Температура, вакуум и давление контролируются встроенными датчиками. Программное обеспечение управляет техпроцессом и контролирует его параметры.

Исполнение по требованиям заказчика

Рабочие размеры автоклава, параметры вакуума, давления и температуры, количество точек создания вакуума определяются техническим заданием. Энергоэффективность обеспечивается правильным выбором параметров техпроцесса и конструктивными особенностями автоклава НПП «Электромаш».
