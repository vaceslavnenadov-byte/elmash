# Новый сайт ООО НПП «Электромаш» (electromash.com)

Статический сайт без CMS и зависимостей: HTML + CSS + немного JavaScript.
Структура меню и разделов повторяет старый сайт, чтобы посетители находили всё на привычных местах.

## Сборка и просмотр

```bash
node build.mjs
```

Готовый сайт появится в папке `dist/`. Его можно открыть в браузере (`dist/index.html`)
или загрузить на любой хостинг как есть.

## Где что менять

| Что | Где |
|---|---|
| Телефоны, e-mail, адрес, реквизиты, ссылки (ВК, каталог PDF, ГОСТы) | `src/site.json` |
| Каталог: электроремонтное, испытательное оборудование, подстанции, новости | `src/data/catalog.json` |
| Тексты страниц | `src/pages/*.html` |
| Шапка, меню, подвал, окно заявки | `src/partials/*.html` |
| Стили | `assets/css/style.css` |
| Картинки | `assets/img/` |

Меню, карточки каталога, новости и поиск по сайту собираются из `catalog.json` автоматически:
достаточно добавить запись и пересобрать сайт.

## Заявки с сайта

Формы «Заказать звонок», «Запросить цену» и форма на странице контактов работают так:

* если в `src/site.json` заполнен `formEndpoint` (адрес обработчика, принимающего JSON POST) — заявка уходит туда;
* если не заполнен — открывается почтовый клиент посетителя с готовым письмом на `sales@electromash.com`.

## Что пока ведёт на старый сайт

Подробных страниц отдельных товаров, новостей, «ГОСТов» и «Статей» не было в присланном архиве,
поэтому кнопки «Подробнее» и эти пункты меню пока открывают соответствующие страницы
`https://electromash.com/...`, а PDF-файлы (каталог, паспорта автоклавов, бланк заявки на аттестацию,
антикоррупционная политика) скачиваются оттуда же. Перед заменой старого сайта эти страницы и файлы
нужно перенести (адрес старого сайта задаётся полем `legacy` в `src/site.json`).
